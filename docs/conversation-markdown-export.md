# 导出当前会话

页面右上角的「导出」按钮将当前打开的会话下载为 UTF-8 `.md` 文件。
文件按显示顺序包含每一轮提问与回答；不会导出其他历史会话、执行图、
后台元数据、账号资料或隐藏的思考文本。导出在浏览器本地完成，不上传内容。

新消息保留回答正文的原始 Markdown，包括代码块、列表和完整链接。
旧版浏览器历史仅保存了渲染后的 HTML，因此会从正文结构恢复 Markdown；
恢复的是内容与结构，不保证与当年的 Markdown 字节完全一致。

空会话不能导出。若回答仍在生成，会保留已提交的提问并明确标注回答尚未完成，
不会把半截回复冒充完整回答。需要完整答案时，请等待生成结束后再导出。

下载文件包含当前会话正文，可能含有用户自己输入的私密信息；请自行核对后再分享。
