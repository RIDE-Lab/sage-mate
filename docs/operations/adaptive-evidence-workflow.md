The one persistent native chat graph now chooses real branches:

- Resolved greetings/session facts go to render without retrieval/model stages.
- Self-contained requests compose an answer without knowledge retrieval.
- Evidence/research requests retrieve authorized context before answering.
- Booking prepares fields and only submits a complete captured request; neither
  branch performs unrelated knowledge retrieval or generation.
- Knowledge writes require explicit authenticated administration capability.
- Source retrieval itself filters Wiki/private readers: the private reader never
  starts for a guest. Member source readers can run concurrently.

answer/route fields which downstream operators can mutate before a sibling guard
is scheduled. Rejoining streams merge complementary outputs, not a join barrier.

which branch was taken. The browser draws edges from those native references;
running-edge animation is absent from completed histories and respects reduced
motion. No raw model reasoning is needed to explain scheduling or evidence.

## Native evidence quality integration (not yet live-qualified)

SAGE now owns `EvidenceWorkflowRuntime`: lossless question partitions, exact
authorized-source coverage witnesses, a conditional single supplement/reassessment
round, constrained source composition, typed research experiment planning and final
source/coverage verification. Remaining evidence gaps are shown as original
question spans, never as claims that facts do not exist. Structural validation
does not certify the model's semantic coverage judgment or the truth of sources.

Coverage wire receipts use source-local inclusive `start_line`/`end_line` ranges.
SAGE numbers the complete source with original line endings, extracts the exact
witness itself, and rejects unknown sources, invalid/empty ranges, stale digests
or tampered receipts. The model no longer retypes quote strings; this removes a
verified false rejection mechanism without approximate matching or weakening
provenance. Final factual rendering still preserves the complete selected source.

Typed HTTP validation failures retain their safe public classification and keep
the ordered native SSE stream open until its terminal record arrives. Failure
and cancellation bubbles retain observed execution/work events; a rejected answer
is not reported as an offline backend or a successful quality check.

Source relevance is now a native SAGE stage before coverage, and again after
repair. The immutable complete authorized candidate snapshot and its digest are
distinct from the selected model input. Literal identifiers in the original
question prefer matching full sources; no discriminating match leaves semantic
retrieval unchanged. This is a source-selection hint, not a fact verifier.
Repair always reselects against the complete accumulated candidates, keeping
stable source IDs. Final rendering verifies both candidate integrity and the
selected request; Twin binds the candidate snapshot to its ACL-resolved hits.
Selected source bodies/links remain complete; unrelated manuals need not be
concatenated into a coverage request merely because retrieval returned them.

Experiment plans now contain typed fault events (`kind`, `target`, `at_step`),
not an independently authored fault-model label and freeform schedule. SAGE
derives the declared injected-fault boundary from every event kind and renders
the same pre-recorded operation-indexed schedule for both groups. Empty events
explicitly mean no injected failure, not a claim of crash resilience. Unknown,
malformed and out-of-order events are rejected. This does not certify feasibility
or scientific relevance; live semantic review remains a release gate.

Live qualification subsequently found a second fault label hidden in freeform
shared conditions. Version 3 experiment requests therefore use a fixed conditions
object (model, hardware, workload, software, precision, warm-up operations and
replay seed), rather than a model-authored list of labels. Fault declarations
belong only in typed events. Performance sampling is independent paired workload
replays with shared inputs/seeds within each pair, not correlated request rows or
per-second metric units. The request version changes the digest/cache identity;
old experiment schemas are not silently accepted. Free-text values still require
semantic review; a structural pass does not guarantee a feasible experiment.

Filtered response hits now carry `evidence_source_id`, the original source-plan
ID, so clients can match canonical source blocks without guessing from array
positions. Old search/history records without a source plan may lack this field.
The real QA observer retains its owner and request ID across queued 429/observer
504 responses; hard capacity rejection remains a failed gate, not a successful
enqueue. It never cancels the producer just because its own observation expires.

Twin supplies only model and ACL-aware read ports in `evidence_ports.py`. The old
direct source-plan generation path is replaced, not retained as a second flow.
Supplement search and hydration use a captured verified identity/source selection;
model suggestions cannot broaden it. Source-grounded requests with zero hits also
enter the same flow; empty-source assessments are deterministic and spend no model
request, then attempt authorized repair before returning an explicit unknown.
Runtime identity answers remain bound to the authoritative runtime provider.
The SAGE plan distinguishes an explicit evidence requirement from opportunistic
retrieval, preserving ordinary advice and conversation memory when Wiki is empty.
Two prior fast-classifier fixtures now additionally require real supplement
execution and an explicit gap for their empty, explicitly selected Wiki, rather
than accepting unconstrained factual prose. Their classifier-free gate is unchanged.

Canonical answer text and presentation blocks come from SAGE's same final
renderer. A permanent child validation failure retains its leaf type through the
native parent boundary; HTTP/Slack treat it as terminal, not retryable generation.

First SAGE-wide run failed 29 tests because the scratch copy omitted tracked
benchmark tools (567 passed, 1 skipped). Copying those tools without changing

evidence policy) passed 597 tests, 1 skipped in 36.98 seconds. The first integrated Twin focused gate passed 100 tests in
60.36 seconds. Expanded integration initially exposed 19 failures from the overly

not evidence of real model quality, neural retrieval performance or live ACLs.
