## 根因与实现

旧路由在自适应计划、提示组装、事实快捷回答和来源工作流入口分别运行主题词判定。“研究问题”“贡献”“负结果”等名词被当成研究评审动作，导致事实查询启动不相关实验规划。

SAGE 现在提供独立于领域、身份和来源选择的 AnswerTask 契约，判断本轮是否明确要求研究评审/前瞻实验。含事实查证的研究请求仍运行相同的来源覆盖工作流；没有添加另一套问答流程。研究请求必须带当前原句中的连续请求片段；片段校验只证明出处，不冒充语义正确性证明。

Twin 通过现有意图调用获得这个决定，并在计划、完整/紧凑提示与 SAGE 执行之间传递同一决定；不再靠主题快路绕过任务分类。缺失任务决定不能被没有原问题的 JSON 形状修复补造，也不能静默回退到主题猜测。仍保留寒暄等自包含任务的快路。意图输出空间从160调为512 token，只用于容纳任务字段和原文片段，没有降低答案预算或更换模型。

最初把研究与“研究+事实”设为两种执行上相同的标签，真实模型对来源限定与混合请求的细分不稳定；最终删掉非必要分类，只保留 facts/research。原始事实反例未改题；混合请求的事实覆盖、独立建议标注和研究执行能力都保留。
